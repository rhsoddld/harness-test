# Skill Index

Repo-local skills define the technical playbooks Codex must read during development.
They complement global Codex skills, but do not depend on them being installed.

## Skills

- `frontend-modern-stack.md`: Next.js, React, TypeScript, Tailwind, accessibility, screenshot evidence.
- `backend-api-stack.md`: API contracts, validation, auth boundaries, error handling.
- `database-postgres-prisma.md`: PostgreSQL, Prisma, migrations, seeds, rollback.
- `container-delivery.md`: Docker/Compose, healthchecks, runtime logs.
- `testing-quality.md`: unit, integration, browser, evidence strategy.
- `security-baseline.md`: secrets, input validation, authz/authn, dependency risk.
