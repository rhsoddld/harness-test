# Context Artifacts

Execution context summaries live here when they should be preserved beyond raw run logs.

## Contents

- `latest-context.md`: optional pointer or summary of the most recent useful run context.
- `<run-id>/context-summary.md`: compact facts, assumptions, decisions, and next steps extracted from a run.

Raw logs remain under `artifacts/runs/`. Durable product or architecture knowledge should be promoted into `docs/`.
